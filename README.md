# Python Blockchain API with FastAPI

A simple blockchain backend developed using Python and FastAPI.

## Features

- Create blockchain
- Add transactions
- SHA-256 hashing
- Proof-of-Work mining
- Blockchain validation
- REST API
- Swagger API documentation

## Technologies Used

- Python
- FastAPI
- Uvicorn
- Pydantic
- SHA-256
- REST API
